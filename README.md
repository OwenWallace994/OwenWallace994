## Current Work

**Innsmouth Archives (Self-Hosted Infrastructure Project)**  
A fully containerized stack running on Linux, with:

- Caddy (reverse proxy and automated HTTPS)
- Dockerized services
- Jellyfin for media streaming
- Immich for photo management and backup
- Prometheus and Grafana for system metrics and dashboards

All services are routed through subdomains under my domain:

- stream.innsmoutharchives.com  
- photos.innsmoutharchives.com  
- metrics.innsmoutharchives.com  

The project includes complete documentation of installation steps, failure points, debugging methods, and system recovery after an OS corruption event.

Repository: **innsmouth-archives-infra**
